Prompt:

Give me the procedure to upload, sync, and manage files on OneDrive.

OneDrive: Upload, Sync & Manage Files

A step-by-step guide for the website and desktop app

Source note: This procedure is compiled from Microsoft's official support pages plus community guides (see Sources). The Agentic RAG knowledge base contained no matching document for this query.

1 Upload files and folders to OneDrive

OneDrive stores 300+ file types. Upload through the website, or drag-and-drop with the desktop app.

Via the OneDrive website

  1. Go to OneDrive.com and sign in with your Microsoft account.
  2. Open My Files (or the target folder). To create one: New → Folder.
  3. Click Upload at the top, then choose Files or Folder.
  4. Select your items and click Open/Upload — they appear in your OneDrive.

Via File Explorer (desktop app installed)

Select your files and drag them onto OneDrive in the Navigation pane.

2 Sync your files

Sync keeps your PC/Mac and the cloud matched — change in one place and it updates everywhere, while synced files stay available offline.

Windows

  1. Install OneDrive (built into Windows 11) from microsoft.com/microsoft-365/onedrive/download.
  2. Open OneDrive, enter your personal or work/school account, and Sign in.
  3. Complete the two setup screens: your OneDrive folder location, and Files On-Demand.

macOS

  1. Install OneDrive, launch setup (Spotlight → “OneDrive”), and sign in.
  2. Choose the folder location, then select which files/folders to sync.

Managing what syncs

  • Personal files live under OneDrive – Personal; work files under OneDrive – [Company].
  • Use Choose folders / Files On-Demand to sync only what you need and save disk space.
  • Right-click the OneDrive folder → Settings → Sync and backup → Manage backup to change backed-up folders.
  • Pause/resume from the taskbar (Windows) or menu bar (macOS) cloud icon; a green checkmark = fully synced.

3 Manage your files

Organize & share

Rename, move, copy, or create folders directly in OneDrive or File Explorer; select a file and use Share to collaborate.

Delete

Select the item(s) and choose Delete (or right-click → Move to trash on Mac). You can multi-select, select all, or select an entire folder first.

Restore

Deleted items go to the OneDrive Recycle Bin (left nav, or Recycle bin in File Explorer) — open it and restore anything removed by mistake. Items are recoverable for a limited time.

Quick tip: A green checkmark on a file means it's fully synced. A blue cloud icon means it's online-only (Files On-Demand) and will download when opened.
